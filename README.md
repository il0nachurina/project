# Хабит — трекер привычек в Telegram

Telegram Mini App для отслеживания полезных привычек: пользователь добавляет привычки, отмечает выполнение за день, данные сохраняются в Telegram CloudStorage. Не нужно ничего устанавливать и регистрироваться.

## Цель

Помочь людям формировать полезные привычки прямо в мессенджере, где они и так проводят время: отдельные приложения неудобно открывать, а заметки не мотивируют.

## Ключевые функции

Уже работает (MVP):
- добавление привычек;
- отметка выполнения одним нажатием;
- сохранение данных в Telegram CloudStorage.

В планах:
- серии (сколько дней подряд выполняется привычка) и недельная статистика;
- бот с напоминаниями (Python, aiogram);
- платная подписка Premium.
